# 东莞市伟创业精密制造有限公司 · 官网原型（内部预览）

给公司内部看的**样板**，不是正式站。

- **首页**：`index.html`
- **全部 300 个页面**：`pages.html`

## 现在是什么状态

- 页眉竖版 logo（图标一行、公司全名一行），页脚横版反白 logo
- 站内链接可以直接点击跳转；原站有但没抓下来的页面点击会提示，不跳转
- 页面文本里的公司名、简称已全部换成伟创业（原抓取来源的品牌信息 0 残留）
- 工厂车间、检测设备、团队照片用的是**太阳美集团**的实拍（伟创业为其子公司）
- 电话、QQ、微信二维码、地址用的是太阳美的联系方式
- **CSS、JS、图片全部本地化**，断网也能正常显示

## SEO 与移动端优化（不改任何文字，只动结构和样式）

- **移动端完整响应式**：补 viewport meta、解除 `body{min-width:1200px}`、
  导航改汉堡菜单+侧边抽屉、右侧客服栏在手机上改底部固定条。
  抽屉用 `transform` 移出屏幕而非 `display:none`，10 个导航链接始终在 DOM 里
- **窄屏版式修复**（`gen-mobile-css.py` 自动生成，433 条覆盖规则）：
  原站是纯 PC 版式，固定像素宽高、浮动分栏、按 1200px 版心算的绝对定位坐标、
  按 1920px 稿写的 vw 字号，在手机上会撑破视口、把正文挤成窄条、
  用 `overflow:hidden` 把正文裁掉，甚至把元素推出容器导致宽度算成 0（正文不渲染）。
  生成器解析 19 个样式表 + 197 个页面的页内 `<style>` + 内联宽度，按模式反推覆盖：
  放开写死的宽高、解开裁切与 line-clamp、分栏改单列、负偏移拉回容器、vw 换算成 px。
  分两档生效：`<=1199px` 只做防溢出（保留多栏），`<=768px` 完整降级。**1200px 以上一像素未动。**
  14 套页面模板逐一实测：横向溢出 0、被裁正文 0、零宽文字 0、过小字号 0
- **性能**：首屏外图片全部 `loading="lazy"`，全站图片补 `width`/`height` 消除 CLS
- **h1 归位**：原站把 h1 用在了站点 logo 上，231 个页面没有主题 h1。
  改为 logo 降级为 div、CMS 标记的 `id="h1_rep_title"` 元素升级为 h1，
  有主题 h1 的页面从 69 页增加到 248 页（只换标签名，文字一字未改）
- **语义地标**：`div.topWrap` → `<header>`，`div.footWrap` → `<footer>`
- **清理原站残留**：删掉原站主的百度/搜狗/神马站长验证码、解开「关于/联系」页上的
  nofollow、2551 个死链加 nofollow、JSON-LD 类型由 SoftwareApplication 改为 Product
  并修正 710 个 404 的 URL、删掉百度统计/CNZZ/百度推送/在线客服插件/手机端跳转脚本/
  友情链接/llms.txt 死链/模板变量残留
- **新增** `sitemap.xml`（按实际页面生成），`robots.txt` 加了 Sitemap 指令

改动前后用 `seo-snapshot.py` 做过机器校验：title / 链接 / alt / description **零变化**。
窄屏版式修复只改了 `assets/brand.css` 一个文件，299 个页面的 HTML 与上一版**逐字节一致**
（仅缓存版本号 `?v=` 变化），正文一个字没动。
